# Agent Workspace

## Windows CMD에서 실행

저장소 루트의 첫 번째 CMD에서 API를 엽니다. 산술 연결부터 확인할 때는 Ollama 없이 로컬 산술 제공자를 사용할 수 있습니다.

```cmd
set "LLM_PROVIDER=local_math"
uv run python -m uvicorn main:app --app-dir apps/api/src
```

두 번째 CMD에서 프론트엔드를 엽니다. Node.js 20.19 이상(20.x) 또는 22.12 이상이 필요합니다.

```cmd
cd apps/web
npm ci
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. Vite는 /api 요청을 FastAPI의 http://127.0.0.1:8000 으로 전달합니다. 다른 포트를 쓰는 경우 Vite를 시작하기 전에 `AGENT_API_URL`을 설정합니다.

## 사용법

1. 기본 개발 사용자 `kim`으로 들어가 **도구 목록**에서 서버 도구를 확인합니다.
2. **시나리오 템플릿 → 계산 도우미 → 템플릿 사용**에서 선택된 도구와 시스템 프롬프트를 검토한 뒤 저장합니다.
3. **내 에이전트 → 이 에이전트로 작업**에서 `123 * 45`를 보냅니다. 답변 아래에서 도구 실행 결과를 펼칠 수 있습니다.
4. 다음 메시지는 같은 서버 세션에서 처리됩니다. 왼쪽 **새 대화**는 새 세션으로 시작합니다. 최근 대화는 현재 페이지에 있는 동안 표시됩니다.
5. 도구 실행에 승인 요청이 있으면, 응답을 기다리는 동안 채팅에서 승인하거나 거절할 수 있습니다.

범용 요청과 템플릿을 사용하려면 Ollama를 실행하고 API를 시작하기 전 `set "LLM_PROVIDER=openai"`, `set "LLM_MODEL=llama3.1:latest"`처럼 설치된 모델을 지정합니다. 산술 제공자는 계산만 처리합니다.

자연어 초안은 프론트의 키워드 규칙으로 만들고, 에이전트는 FastAPI에 저장합니다. 기존 브라우저 에이전트는 자동 이관되지 않습니다. 서버 저장소는 메모리 기반이므로 재시작하면 에이전트와 세션이 초기화됩니다. 기존 브라우저 도구 메타데이터는 **도구 추가 초안**에서 볼 수 있습니다. 실제 실행에는 Python 도구 구현과 서버 레지스트리 등록이 필요합니다.

정적 배포 시에는 웹 서버에서 같은 출처의 /api 경로를 FastAPI로 전달해야 합니다.
