# Agent Workspace

React와 Vite로 만든 로컬 프론트엔드 데모입니다.

## 실행

Node.js 20.19 이상(20.x) 또는 22.12 이상이 필요합니다. 저장소 루트의 PowerShell에서 실행합니다.

```powershell
cd apps/web
npm.cmd ci
npm.cmd run dev
```

터미널에 표시된 주소를 브라우저에서 엽니다. 기본 주소는 http://localhost:5173 입니다. 프로덕션 빌드는 `npm.cmd run build`로 확인할 수 있습니다.

## 사용법

1. 왼쪽 **에이전트 만들기**에서 원하는 역할을 자연어로 입력하고 **초안 생성**을 누릅니다. 이름, 설명, 시스템 프롬프트, 도구를 확인하고 저장합니다.
2. **내 에이전트**에서 에이전트를 선택해 설정을 수정하고 **변경사항 저장**을 누릅니다.
3. **이 에이전트로 작업**을 누르거나 **작업 채팅** 상단에서 에이전트를 선택합니다. Enter로 전송하고 Shift+Enter로 줄바꿈합니다.
4. **시나리오 템플릿**에서 회의록 정리, 코드 리뷰, 업무 계획 중 하나를 고릅니다. **템플릿 사용**을 누르면 설정이 채워진 초안이 열립니다. 저장 후 작업 채팅에서 선택할 수 있습니다.
5. 왼쪽 **도구 목록**에서 등록된 도구를 확인합니다. **도구 추가**에서 이름, 고유 ID, 설명을 입력해 저장하면 같은 브라우저에서 목록에 남고 에이전트 설정에서 선택할 수 있습니다. 추가한 도구의 실제 실행에는 백엔드 연동이 필요합니다.

**등록된 도구**에서 백엔드와 같은 ID의 덧셈(`add`), 뺄셈(`subtract`), 곱셈(`multiply`)을 선택할 수 있습니다. 도구를 켜고 저장한 에이전트에 `12 + 3`, `12 - 3`, `12 * 3` 같은 식을 보내면 브라우저에서 계산합니다.

초안 생성은 입력 키워드로 도구를 선택합니다. 채팅은 선택한 도구의 규칙 기반 예시 결과와 설정된 시스템 프롬프트를 표시합니다. 실제 LLM 호출과 외부 도구 실행은 연결되어 있지 않습니다. 에이전트 설정은 브라우저의 로컬 스토리지에 저장되고, 대화는 페이지를 새로고침하면 초기화됩니다.
